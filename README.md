# Urban Engine Flow

Urban Engine Flow is an intelligent transportation analysis system that answers natural-language queries on urban road networks using graph algorithms.

## Features

- Shortest Path using Dijkstra's Algorithm
- Maximum Flow using Dinic's Algorithm
- Minimum Cut Analysis
- Python Query Engine
- JSON-based communication between Python and C++

## Technologies

- C++
- Python
- JSON (nlohmann/json)

## Algorithms

- Dijkstra's Shortest Path
- Dinic's Maximum Flow
- Minimum Cut
